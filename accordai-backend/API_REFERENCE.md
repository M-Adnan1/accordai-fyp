# AccordAI Backend — API Reference

AI customer-service voice agent backend. Multi-tenant: every piece of data is scoped to a
`Client` (tenant), identified at call time by the Twilio number that was dialed.

- **Base URL (dev):** `http://localhost:8000`
- **Interactive docs:** `GET /docs` (Swagger UI), `GET /redoc` — auto-generated by FastAPI.
- **CORS:** only `http://localhost:3000` is allowed (`allow_credentials=True`, all methods/headers).

---

## Authentication

**JWT bearer-token auth** protects every admin/data endpoint. The business model: one owner
account = one tenant. Signup creates a `Client` (tenant) plus its first user (`role: admin`);
login is email + password (emails are globally unique).

| Surface | Auth |
|---|---|
| Voice webhooks (`/voice/*`) | Public. Intended to be called by Twilio; tenant is derived from the dialed number. **Twilio request-signature validation is NOT implemented.** |
| Auth (`/auth/signup`, `/auth/login`) | Public. `/auth/me` requires a bearer token. |
| Admin/data endpoints (`/documents/*`, `/analytics/*`, `/tools/*`) | **`Authorization: Bearer <token>` required.** Tenant context comes exclusively from the authenticated user's `client_id` — caller-supplied `client_id` params are gone (and ignored if sent). Mutating endpoints additionally require `role: admin`; `member` accounts are read-only. |
| Root/health (`/`, `/health`) | Public. |

- Tokens are HS256 JWTs signed with `JWT_SECRET_KEY`, expiring after `ACCESS_TOKEN_EXPIRE_MINUTES`
  (default 24h). No refresh tokens — re-login on expiry (future work).
- `401` = missing/invalid/expired token or deactivated account; `403` = valid token, insufficient role.
- Dev seed accounts (created by `scripts/migrate_auth.py`, documented there — never hardcoded in
  app logic): `admin@sunshine.demo`, `member@sunshine.demo`, `admin@bellavista.demo`.

---

## Conventions

- **Tenant scoping** — every data endpoint operates on the authenticated user's tenant; there is
  no way to address another tenant's data.
- **Voice endpoints** consume `application/x-www-form-urlencoded` bodies (Twilio's format) and
  return **TwiML** (`application/xml`), not JSON.
- **Data endpoints** consume/return `application/json`.
- Timestamps are ISO-8601 with timezone (e.g. `2026-07-08T16:09:22.761466+00:00`).

# Auth — prefix `/auth`

## POST `/auth/signup`
Create a new tenant + its owner account, and log in atomically.

- **Auth:** none (public).
- **Request body:** `business_name` (2-100 chars), `email` (valid, globally unique),
  `password` (8-72 chars), `full_name` (optional).
- **Response `201`:** `{ "access_token", "token_type": "bearer", "user": { id, email, full_name, role, client_id, client_name } }`
- **Errors:** `409` email already registered; `422` validation.

## POST `/auth/login`
- **Auth:** none (public).
- **Request body:** `email`, `password`.
- **Response `200`:** same shape as signup.
- **Errors:** `401` wrong credentials (identical message for unknown email vs wrong password) or deactivated account.

## GET `/auth/me`
- **Auth:** **Bearer token.**
- **Response `200`:** `{ id, email, full_name, role, client_id, client_name }`

# Account / Settings — prefix `/account`

## GET `/account/tenant`
The authenticated user's tenant record plus the static voice-webhook URL.

- **Auth:** **Bearer token** (any authenticated user).
- **Response `200`:** `{ id, name, twilio_number (nullable), voice, created_at, webhook_url }`
  — `webhook_url` is `PUBLIC_BASE_URL` + `/voice/incoming`; it is the same for every tenant
  (incoming calls route to a tenant by the dialed number).

## PATCH `/account/twilio-number`
Set, replace, or clear the tenant's Twilio number. Takes effect on the next incoming call.

- **Auth:** **Bearer token, admin role required.**
- **Request body:** `{ "twilio_number": "+13526236826" }` — or `null` to clear. Input is
  normalized (spaces/dashes/dots/parens stripped, leading `00` → `+`) then validated against
  E.164 (`^\+[1-9]\d{7,14}$`). No country-code guessing: `+` is required.
- **Response `200`:** updated tenant, same shape as `GET /account/tenant`.
- **Errors:** `422` not E.164 after normalization; `409` number already used by another tenant.

## POST `/account/change-password`
- **Auth:** **Bearer token** (any authenticated user).
- **Request body:** `{ "current_password", "new_password" }` (new: 8-72 chars).
- **Response `200`:** `{ "message": "Password updated successfully." }`
- **Errors:** `400` current password incorrect; `422` new password too short/long.

# Voice (Twilio webhooks) — prefix `/voice`

All endpoints in this group are `POST`, consume Twilio form-encoded fields, and return TwiML XML.
They are designed to be configured as the voice webhook on a Twilio phone number.

## POST `/voice/incoming`
Entry point for an inbound call. Resolves the tenant from the dialed number, creates a `Call`
record, and speaks the tenant's greeting.

- **Auth:** none (Twilio webhook)
- **Request body (form-encoded):**

| Field | Type | Notes |
|---|---|---|
| `CallSid` | string | Twilio call identifier |
| `From` | string | Caller's number |
| `To` | string | Dialed number — used to look up the active `Client` |

- **Response `200` (TwiML):** greeting + a `<Gather input="speech">` posting to `/voice/process`.
  If **no active client** matches `To`, returns a TwiML "this number is not in service" message
  followed by `<Hangup/>` (still HTTP `200`).

```xml
<?xml version="1.0" encoding="UTF-8"?>
<Response>
  <Say voice="Polly.Joanna">Hello! Thanks for calling Bella Vista Restaurant. How can I help you today?</Say>
  <Gather input="speech" action="/voice/process" method="POST" speechTimeout="auto" language="en-US"/>
  <Say>I didn't hear anything. Please call back when you're ready.</Say>
  <Hangup/>
</Response>
```

## POST `/voice/process`
Handles one spoken turn: persists the message, runs the RAG + LLM + tool-calling pipeline, and
speaks the reply. This is where the tool-calling / confirmation flow runs.

- **Auth:** none (Twilio webhook)
- **Request body (form-encoded):**

| Field | Type | Notes |
|---|---|---|
| `SpeechResult` | string | Transcribed caller speech (may be empty) |
| `CallSid` | string | Must match a `Call` created by `/voice/incoming` |

- **Behavior notes:**
  - Unknown `CallSid` → graceful "something went wrong" TwiML + `<Hangup/>`.
  - Empty `SpeechResult` → "Sorry, I didn't catch that" + redirect back to `/voice/incoming`.
  - Goodbye intent → redirect to `/voice/rate` (skipped while a tool confirmation is pending).
  - Otherwise → LLM reply, then a `<Gather>` for the next turn.
- **Response `200` (TwiML):** e.g.
```xml
<?xml version="1.0" encoding="UTF-8"?>
<Response>
  <Say voice="Polly.Joanna">Just to confirm, I have you down for a table for 4 tonight at 7 PM under the name Ahmed — is that correct?</Say>
  <Gather input="speech" action="/voice/process" method="POST" speechTimeout="auto" language="en-US">
    <Say voice="Polly.Joanna">Is there anything else I can help you with?</Say>
  </Gather>
  <Say voice="Polly.Joanna">Thank you for calling. Goodbye!</Say>
  <Redirect>/voice/rate</Redirect>
</Response>
```

## POST `/voice/rate`
Prompts the caller to rate the call via keypad (DTMF).

- **Auth:** none (Twilio webhook)
- **Request body (form-encoded):**

| Field | Type | Notes |
|---|---|---|
| `CallSid` | string | Used to resolve the tenant voice |

- **Response `200` (TwiML):** a `<Gather input="dtmf" numDigits="1">` posting to `/voice/save-rating`,
  with a no-input fallback that thanks the caller and hangs up.

## POST `/voice/save-rating`
Stores the satisfaction rating and ends the call.

- **Auth:** none (Twilio webhook)
- **Request body (form-encoded):**

| Field | Type | Notes |
|---|---|---|
| `CallSid` | string | Call to update |
| `Digits` | string | `"1"` = satisfied, `"0"` = not satisfied; anything else = invalid |

- **Response `200` (TwiML):** a thank-you/apology `<Say>` matching the rating, then `<Hangup/>`.

## POST `/voice/status`
Twilio status-callback. Updates call status/duration on completion or failure.

- **Auth:** none (Twilio webhook)
- **Request body (form-encoded):**

| Field | Type | Notes |
|---|---|---|
| `CallSid` | string | Call to update |
| `CallStatus` | string | `"completed"` → COMPLETED; `busy`/`failed`/`no-answer` → FAILED |
| `CallDuration` | integer | Seconds (on completion) |

- **Response `200`:** empty body (no TwiML).

# Documents (RAG knowledge base) — prefix `/documents`

Per-tenant document store. Files are saved under `DOCUMENTS_DIR/<client_id>/` and chunked into
ChromaDB with `client_id` metadata so retrieval never crosses tenants.

## POST `/documents/upload`
Upload and ingest a document into a client's knowledge base.

- **Auth:** **Bearer token, admin role required.** Tenant is the authenticated user's client.
- **Query params:** none
- **Request body:** `multipart/form-data` with a single `file` field. Allowed extensions:
  `.pdf`, `.txt`, `.md`.
- **Response `200`:**
```json
{
  "message": "Document ingested successfully.",
  "filename": "faq.pdf",
  "chunks_ingested": 12
}
```
- **Errors:** `400` unsupported file type; `500` file could not be read/parsed.

## GET `/documents/list`
List a client's uploaded files and its total chunk count in ChromaDB.

- **Auth:** **Bearer token** (any authenticated user). Tenant is the authenticated user's client.
- **Query params:** none
- **Request body:** none
- **Response `200`:**
```json
{
  "files": ["faq.pdf", "policy.txt"],
  "total_chunks": 34
}
```

## DELETE `/documents/delete/{filename}`
Delete a file from disk and remove its chunks from ChromaDB, scoped to one client.

- **Auth:** **Bearer token, admin role required.** Tenant is the authenticated user's client.
- **Path params:** `filename` (string)
- **Query params:** none
- **Request body:** none
- **Response `200`:**
```json
{ "message": "'faq.pdf' deleted from knowledge base." }
```
- **Note:** returns `200` even if the file was not present on disk (chunk deletion still runs).

# Tools (function calling) — prefix `/tools`

Admin endpoints for the tools a client's AI agent may call mid-conversation. `auth_credential` is
Fernet-encrypted at rest and is **never** returned in any response.

## POST `/tools/generate-schema`
AI-assisted: turn a plain-English description into a reviewed JSON Schema. **Saves nothing** — the
owner reviews/edits, then calls `/tools/create`.

- **Auth:** **Bearer token, admin role required.** (Persists nothing; costs LLM tokens.)
- **Request body (`application/json`):**
```json
{ "description": "Book a table. Caller must give party size, time, and their name; drop-off optional." }
```
| Field | Type | Required | Notes |
|---|---|---|---|
| `description` | string | yes | min length 10 |

- **Response `200`:**
```json
{
  "name": "reserve_table",
  "description": "when the caller wants to book a table",
  "parameters": {
    "type": "object",
    "properties": {
      "party_size": { "type": "integer", "description": "Number of people" },
      "time":       { "type": "string",  "description": "Requested time" },
      "name":       { "type": "string",  "description": "Reservation name" }
    },
    "required": ["party_size", "time", "name"]
  }
}
```
- **Errors:** `422` if a valid schema could not be produced after one retry (message suggests
  rephrasing).

## POST `/tools/create`
Persist a reviewed tool definition for a client. Re-validates the schema, validates the endpoint
URL (SSRF protection), and encrypts any credential.

- **Auth:** **Bearer token, admin role required.** Tenant is the authenticated user's client.
- **Query params:** none
- **Request body (`application/json`):**

| Field | Type | Required | Default | Notes |
|---|---|---|---|---|
| `name` | string | yes | — | lowercase snake_case (`^[a-z][a-z0-9_]{0,63}$`) |
| `description` | string | yes | — | non-empty; tells the LLM *when* to call the tool |
| `parameters` | object | yes | — | valid JSON Schema, `"type": "object"` with `properties` |
| `endpoint_url` | string | yes | — | http/https, public host only (SSRF-checked) |
| `http_method` | string | no | `"POST"` | one of GET/POST/PUT/PATCH/DELETE |
| `auth_type` | string | no | `"none"` | `bearer` \| `api_key_header` \| `none` |
| `auth_credential` | string\|null | conditional | `null` | **required if `auth_type != "none"`**; stored encrypted |
| `auth_header_name` | string\|null | no | `null` | header for `api_key_header` (defaults to `X-API-Key`) |
| `requires_confirmation` | bool | no | `true` | if true, the agent reads details back and waits for spoken confirmation before executing |

- **Response `200`:** the created tool (**no `auth_credential`**):
```json
{
  "id": 2,
  "client_id": 1,
  "name": "reserve_table",
  "description": "when the caller wants to book a table",
  "parameters_schema": { "type": "object", "properties": { }, "required": [] },
  "endpoint_url": "https://api.example.com/bookings",
  "http_method": "POST",
  "auth_type": "bearer",
  "auth_header_name": null,
  "requires_confirmation": true,
  "is_active": true,
  "created_at": "2026-07-08T16:09:22.761466+00:00"
}
```
- **Errors:** `422` invalid name/description/schema, disallowed method/auth_type, missing credential,
  or SSRF-rejected URL (private/reserved IP, localhost, non-http(s), embedded credentials);
  `409` a tool with that name already exists for the client.

## PATCH `/tools/update`
Apply a **partial** update to an existing tool owned by the client. Only the fields present in the
request body are changed; anything omitted is left untouched. Re-validates the resulting schema,
re-checks the endpoint URL (SSRF) when changed, and re-encrypts the credential only when a new one
is supplied.

- **Auth:** **Bearer token, admin role required.** Tenant is the authenticated user's client.
- **Query params:** `tool_id` (int, required)
- **Request body (`application/json`):** every field is optional; send only what changes.

| Field | Type | Notes |
|---|---|---|
| `name` | string | lowercase snake_case; validated with description + parameters as a whole |
| `description` | string | non-empty |
| `parameters` | object | valid JSON Schema, `"type": "object"` with `properties` |
| `endpoint_url` | string | http/https, public host only (SSRF-checked) |
| `http_method` | string | one of GET/POST/PUT/PATCH/DELETE |
| `auth_type` | string | `bearer` \| `api_key_header` \| `none` — switching to `none` clears the stored credential/header |
| `auth_credential` | string | new secret to rotate to; stored encrypted. Omit to keep the current one |
| `auth_header_name` | string\|null | header for `api_key_header` (defaults to `X-API-Key`) |
| `requires_confirmation` | bool | |
| `is_active` | bool | set `false` to disable the tool without deleting it |

- **Response `200`:** the updated tool, identical in shape to the `/tools/create` response
  (**no `auth_credential`**).
- **Errors:** `422` empty body, invalid name/description/schema, disallowed method/auth_type,
  missing credential when switching to a credentialed `auth_type`, or SSRF-rejected URL;
  `404` no tool with that `tool_id` belongs to this `client_id`;
  `409` renaming to a name another tool of this client already uses.

## DELETE `/tools/delete/{tool_id}`
**Soft delete** a tool owned by the client — sets `is_active=false`. The row is kept because
`tool_call_logs` reference the tool by id, so hard-deleting would break the audit trail. A
deactivated tool disappears from `/tools/list` and is no longer offered to the agent; it can be
re-enabled with `PATCH /tools/update` (`is_active=true`).

- **Auth:** **Bearer token, admin role required.** Tenant is the authenticated user's client.
- **Path params:** `tool_id` (int, required)
- **Query params:** none
- **Request body:** none
- **Response `200`:** `{ "message": "Tool '<name>' deactivated.", "id": <tool_id> }`
  (already-inactive tools return a `"was already inactive"` message and the same `200`).
- **Errors:** `404` no tool with that `tool_id` belongs to this `client_id`.

## GET `/tools/list`
Active tools for a client (credentials excluded).

- **Auth:** **Bearer token** (any authenticated user). Tenant is the authenticated user's client.
- **Query params:** none
- **Request body:** none
- **Response `200`:** array of tool objects, each identical in shape to the `/tools/create`
  response (again, **no `auth_credential`**).
